# Basel Beer Mile website

Open `index.html` locally or publish the folder to GitHub Pages.

## Structure

- `index.html` — complete single-page website
- `assets/hero-basel-runner.jpg` — generated Basel runner hero image
- `assets/about-basel-runner.jpg` — generated event image
- `assets/sponsors-cans.jpg` — generated sponsor-can visual
- `assets/basel-details.jpg` — generated Basel skyline strip
- `assets/basel-beer-mile-full-mockup.jpg` — original full-page visual reference

## Important

The sponsor-can artwork is generated concept artwork. Before publishing,
replace it with approved logo/product photography supplied by the actual
sponsors.

The Google Form is intentionally a placeholder. Replace the `#` URL in
`index.html` when registration is ready.
